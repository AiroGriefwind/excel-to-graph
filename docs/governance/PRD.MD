# PRD

## 核心目标
构建一个基于 Streamlit 的多 Excel 数据分析应用，让用户通过图形化界面完成：
- 多文件上传与统一解析；
- 类似 Excel 筛选 + 汇总公式的统计分析；
- 结果图表化展示；
- 筛选条件保存与一键复用。

## 功能范围
### 必做功能
1. 多 Excel 上传（同类报表格式）。
2. 自动解析：支持前置标题/时间行，按第 4 行表头读取数据。
3. 条件筛选：平台、日期区间、标题关键字、形式。
4. 汇总指标：条数、浏览量总和、互动量总和。
5. 图表：至少饼图（平台占比）+ 折线图（按日期趋势）。
6. 内容列表：折叠区 + 卡片化展示每条贴文信息。
7. 筛选预设：可命名保存、列出并一键应用。
8. 统计报告导出：预览汇总表（锚定分类 + 新形式自动成行，總數=全量），并下载 `.docx`。

### 非目标（当前版本）
- 复杂权限系统与多用户隔离。
- 云端数据库存储。
- 复杂机器学习分类。

## 成功指标（必须完成）
- 上传 2+ 份样本 Excel 后页面可稳定显示分析结果。
- 当筛选 `platform=某值` 时，条数与浏览量可正确联动更新。
- 图表能跟随筛选条件实时刷新。
- 可保存至少 1 组筛选条件并在刷新后仍可读取。
- 基础冒烟脚本通过（解析、筛选、聚合、预设读写）。

## 用户体验要求
- 主页面结构：标题 -> 已保存筛选 -> 筛选器折叠区 -> 图表区 -> 内容区。
- 侧边栏：上传区 + 当前 Excel 列表。
- 内容卡片具备轻量动画/过渡反馈。

## 实现注记（当前版本）
- “保存筛选条件”采用 `popover` 交互实现确认与命名。
- 预设默认持久化到 `.streamlit/filter_presets.json`。
- 运行依赖通过 `requirements.txt` 管理。
